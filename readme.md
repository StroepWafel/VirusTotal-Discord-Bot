Make sure you are in this directory and install requirements from cmd with `pip install -r requirements.txt`

I will go more over the setup in this readme when i get around to it but basically you need to make a bot and when making the OAuth2 URL, give it these permissions:
Scopes:
- bot
Bot Permissions:
- Change nickname
- View Channels
- Send Messages
- Send Messages in Threads
- Embed links
- Read Message History
- Add reactions
